# Mexa Motion Brand Guidelines

## Logo Usage

### Primary Logo
The primary logo consists of a rounded square with a gradient background (#1152DF to #3B82F6) and a white forward arrow path.

### Clear Space
Maintain clear space equal to the height of the "M" in "Motion" on all sides of the logo.

### Minimum Size
- Digital: 32px height minimum
- Print: 0.5 inches height minimum

### Logo Variations
1. **Primary** - Gradient background with white arrow (preferred)
2. **White** - White background with gradient arrow (for dark backgrounds)
3. **Monochrome** - Single color (#1152DF or white)

## Color Palette

### Primary Colors
- **Mexa Vivid Blue**: #1152DF (Primary brand color)
- **Electric Blue**: #3B82F6 (Secondary accent/glow)

### Neutral Colors
- **Deep Slate Charcoal**: #0F172A (Primary text)
- **Subtle Body Text**: #475569 (Secondary text)
- **Muted Text**: #94A3B8 (Tertiary text)
- **White**: #FFFFFF
- **Light Background**: #F8FAFC
- **Border**: #E2E8F0

### Glassmorphism
- Background: rgba(255, 255, 255, 0.85)
- Border: rgba(226, 232, 240, 0.6)
- Blur: blur(12px)
- Shadow: 0 20px 40px -15px rgba(17, 82, 223, 0.08)

## Typography

### Primary Font: Inter
- Weights: 400 (Regular), 500 (Medium), 600 (Semi-bold), 700 (Bold)
- Usage: Body text, UI elements, forms, navigation

### Display Font: Poppins
- Weights: 600 (Semi-bold), 700 (Bold), 800 (Extra-bold)
- Usage: Headlines, titles, hero text, statistics

### Monospace Font: JetBrains Mono
- Weights: 400 (Regular), 500 (Medium)
- Usage: Code snippets, technical data

## Visual Style

### Glassmorphism Cards
- Background: rgba(255, 255, 255, 0.7-0.85)
- Backdrop filter: blur(12px)
- Border: 1px solid rgba(226, 232, 240, 0.6)
- Border radius: 16px (cards), 24px (large cards)
- Shadow: 0 20px 40px -15px rgba(17, 82, 223, 0.08)

### Buttons
- **Primary**: Gradient (#1152DF to #3B82F6), white text, rounded-full
- **Secondary**: Glassmorphism, border, text color
- **Ghost**: Transparent, text color change on hover

### Animations
- Transition: 250ms ease (default), 400ms ease (slow), 500ms cubic-bezier(0.34, 1.56, 0.64, 1) (spring)
- Hover: scale(1.02-1.04), translateY(-2px to -8px)
- Focus: 2px solid #1152DF outline with 2px offset

## Iconography
- Style: Outlined, 2px stroke weight
- Corner radius: 2px
- Size: 24px standard, 20px small, 32px large

## Photography Style
- Bright, natural lighting
- Diverse representation
- Modern workspace environments
- Behind-the-scenes creative process
- Color grading: Slight blue tint in shadows

## Voice & Tone
- Professional yet approachable
- Confident but not arrogant
- Creative and innovative
- Clear and concise
- Action-oriented

## Do's and Don'ts

### Do's
- Use primary logo on light backgrounds
- Use white logo on dark/colored backgrounds
- Maintain clear space
- Use approved color values exactly
- Apply glassmorphism consistently

### Don'ts
- Don't stretch or distort the logo
- Don't change logo colors
- Don't place logo on busy backgrounds without clear space
- Don't use unapproved fonts
- Don't use drop shadows on logo
- Don't rotate the logo
